# CODSOFT Web Development Projects

This repository contains a collection of frontend web development projects. These projects demonstrate practical knowledge in HTML, CSS, and JavaScript through real-world web design tasks.

## Projects Included

### 1. Landing Page
- A responsive and visually appealing landing page.
- Features multiple sections including header, services, and contact.
- Built with HTML and CSS to practice layout and styling.

### 2. Portfolio Website
- A personal portfolio website to showcase skills, certifications, and projects.
- Includes smooth navigation and section-based layout.
- Designed with a focus on professionalism and responsiveness.

### 3. Calculator
- A functional calculator built using JavaScript.
- Supports basic arithmetic operations: addition, subtraction, multiplication, and division.
- Styled with CSS for a clean and modern UI.

### 4. Food Restaurant Website
- A responsive website for a fictional restaurant.
- Contains homepage, menu, and contact sections.
- Developed to practice layout structuring, image integration, and responsive design.

## Technologies Used
- HTML5  
- CSS3  
- JavaScript
